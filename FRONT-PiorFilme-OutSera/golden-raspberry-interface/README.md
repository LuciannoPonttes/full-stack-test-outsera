# golden-raspberry-interface

Front-end Angular para leitura dos indicados e vencedores da categoria Pior Filme do Golden Raspberry Awards.

## Funcionalidades

- Dashboard com 4 painéis.
- Lista de filmes com paginação.
- Filtro por ano.
- Filtro por vencedor.
- Testes unitários.

## API usada

https://challenge.outsera.tech/api/movies

## Rodar

```bash
npm install
npm start
```

Acesse:

```text
http://localhost:4200
```

## Testes

```bash
npm test
```

## Build

```bash
npm run build
```
